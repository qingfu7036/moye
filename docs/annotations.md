# 区域标记与本书仓库

版本：1.4.0  
状态：Windows PDF/EPUB 已实现并通过集成测试；Android 构建通过、运行未验证。

## 使用方式

1. 打开 PDF 或 EPUB，进入阅读器。
2. 点击右下角浮标 **“标记区域”**（裁剪图标）。
3. 在正文上拖出一个长方形；松手后会自动截取该区域。
4. 在弹窗里填写备注，点击“保存标记”。备注可以为空。
5. 返回书库，点击书籍详情里的 **“本书标记与备注”**。
6. 在本书仓库中按备注/摘录搜索，点击标记查看截图和原文引用。
7. 再次打开同一本书时，标记框会显示在保存时的页码/章节位置，点击标记可查看备注。

## 数据存储

- 元数据：SQLite `annotations`（schema v2）。
- 截图：`attachments/annotations/<annotation-id>.png`。
- 矩形使用**归一化坐标**（0..1），相对阅读器可视内容区；不是绝对像素。
- PDF 记录 `page_number`；EPUB 记录 `chapter_index` + `block_index`。
- 删除书籍时，`annotations` 通过外键级联删除；标记截图由删除流程清理。
- 备注搜索使用参数绑定和 `LIKE ... ESCAPE '!'`。

## 书签与全局仓库

- 阅读页“更多阅读工具”可添加/跳转/删除书签。
- 底部导航“标记”进入跨书知识仓库，按书名、备注或原文搜索。
- 删除书籍时可选择“保留标记并删书”：区域标记和截图保留在知识仓库，书签随书删除；
- 不保留时会明确显示将删除的标记/书签数量。

## 当前限制

- 标记框位置按“页码/章节 + 可视区域归一化矩形”恢复；改变窗口大小、字号或滚动位置后，框选位置只能近似对齐。
- 尚未实现文字级选区或跨页/跨章节标记；当前是矩形截图标记。
- 备注为空也允许保存；仓库显示“（无备注）”。
- 独立笔记、文字级摘录/高亮、标签关联和标记导出仍是后续工作。
