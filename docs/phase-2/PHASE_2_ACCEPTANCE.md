## 范围决定

用户已明确：**DOCX 阅读器不做，不需要；V1 阅读器只覆盖 PDF 和 EPUB。**

- DOCX 仍可作为文件导入并读取元数据/封面，保留在书库中。
- DOCX 不显示“开始阅读”，不进入 Phase 2 阅读验收。
- 标注、知识仓库、TTS、备份属于 Phase 3–5，不计入 Phase 2 门禁。
- PDF 文字选择/复制已按用户决定移除，不再作为当前 V1 阅读切片的验收项。

以下 A–D 全部满足，Phase 2 才能标记为通过。任一项没有真实证据，都只能算“部分完成”。

## A. PDF 阅读

- [ ] 打开 10 本真实 PDF：文字型、扫描型、带目录、带图片、带表格、加密/损坏样本各至少 1 本。
- [ ] 页面渲染正确，连续滚动不白屏、不闪退。
- [ ] 缩放：放大、缩小、适应宽度、适应页面。
- [ ] 单页、连续滚动、双页模式至少各验证一次；未实现的模式明确记录为“未实现”。
- [ ] 页码跳转、上一页/下一页。
- [ ] 有目录的 PDF 能打开目录并跳转。
- [ ] 文字选择与复制；扫描型 PDF 明确提示“无文字层”。
- [ ] 书内全文搜索，能定位结果并跳到对应页。
- [ ] 关闭进程重开后恢复到上次页码与页内位置。
- [ ] Windows 与 Android 真机各完成一次。

## B. EPUB 阅读

- [ ] 打开 10 本真实 EPUB3/EPUB2：含图片、脚注、表格、ruby、CSS 排版、复杂样式各至少 1 本。
- [ ] 动态排版：字体、字号、行距、段落间距、阅读背景。
- [ ] 章节目录、章节跳转、上一章/下一章。
- [ ] 图片、链接、脚注可读；不支持的样式要有降级，不崩溃。
- [ ] 位置恢复使用 CFI 或“spine + 元素 + 字符偏移”的稳定锚点，不能用“第几页”冒充 EPUB 位置。
- [ ] 关闭进程重开后恢复章节与段内位置。
- [ ] Windows 与 Android 真机各完成一次。

> 当前 EPUB 使用自建解析器/渲染器，已通过基础阅读切片；它尚未完成 Phase 0 要求的“生产引擎对比”，不能据此宣称 EPUB 已达 V1 最终质量。

## C. 搜索与阅读设置

- [ ] PDF/EPUB 书内搜索：关键词输入、结果计数、上一处/下一处、跳转高亮。
- [ ] 阅读设置持久化：字体、字号、行距、段落间距、背景、阅读模式。
- [ ] 设置只影响阅读器，不破坏书库和数据库。
- [ ] 明/暗主题在阅读器内实际生效。
- [ ] 书库搜索（书名/作者/标签）保持 Phase 1 行为，不能回归。

## D. 阅读记忆、可靠性与跨平台

- [ ] 记录最后阅读时间、页码/CFI/段落、阅读进度、当前模式、字体设置。
- [ ] 正常关闭、强制结束进程、系统重启三种情况下都不丢已保存位置。
- [ ] 阅读进度写入失败时给出提示，不静默丢失。
- [ ] 100 本书库、单本 200 MB 以上 PDF、长 EPUB、损坏文件的压力测试。
- [ ] 阅读过程中退出/切后台/旋转屏幕（Android）不崩溃。
- [ ] Phase 1 的测试、PDF 集成测试、EPUB 集成测试全部保持通过。
- [ ] Android 真机完成 PDF 与 EPUB 各至少一本的打开、翻页/滚动、重启恢复。
