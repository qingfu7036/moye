# 系统语音朗读（最小 V1）

状态：Windows 已接入 EPUB/PDF 阅读器；语音队列使用系统 TTS，句子级推进。Android 构建路径已接入，真机运行未验证。

## 1. 当前范围

- 阅读页右上角“朗读”按钮。
- 系统声音选择、语速调节。
- 播放、暂停、停止、上一句、下一句。
- 逐句朗读，引擎完成回调后推进。
- EPUB 跨段落、跨章节连续朗读，并跟随滚动到当前段落。
- PDF 从当前页开始，读完自动加载下一页；扫描页会跳过并提示。
- 当前朗读句显示在朗读面板；EPUB 当前段落有淡色高亮。
- 朗读位置写入 `speech_progress`，与 `reading_progress` 分开保存。

## 2. 明确不做

- 单词级时间戳/卡拉 OK 式逐字高亮。
- Android 后台播放、锁屏控制、MediaSession。
- 音频文件导出。
- 云端语音或需要联网的 TTS。

## 3. 实现边界

`lib/core/tts/tts_service.dart` 是平台适配层：

- 一次只提交一个句子，避免依赖 Windows 不稳定的词边界回调。
- PDF 页面文本按需加载，不一次性抽取整本书。
- EPUB 利用已解析的块文本，不额外解析 HTML。
- 当前句变化时通过 `TtsSegment` 回传页码/章节/块索引，阅读器据此跳转。

## 4. 当前限制

- 朗读面板显示当前句；正文中只有 EPUB 段落级高亮，不是句内高亮。
- 朗读位置已保存，但重新打开时不会自动回到上次朗读位置；当前从阅读位置开始。
- Windows 已验证声音枚举和朗读队列；Android 仍需真机测试声音包与暂停行为。
- PDF 扫描页没有文字层，无法朗读。
